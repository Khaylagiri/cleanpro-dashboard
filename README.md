# CleanPro – Cleaning Service Web Application

## About the Project

CleanPro is a simple web-based application developed to facilitate the ordering of cleaning services. This project integrates **Midtrans Payment Gateway** to support online payment transactions, allowing users to complete payments through an integrated payment system.

The application demonstrates the implementation of a digital transaction process by connecting a web application with an external payment gateway.

## Key Features

- Cleaning service ordering
- Midtrans Payment Gateway integration
- Online payment processing
- Transaction status handling
- Payment notification integration

## Payment Integration

CleanPro uses **Midtrans** as its payment gateway to process online transactions. The integration connects the application with Midtrans to handle payment requests and receive transaction status updates.

## Technologies Used

- Web Development
- Midtrans Payment Gateway
- Backend Integration
